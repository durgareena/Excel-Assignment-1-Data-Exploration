# Excel Assignment 1 – Data Exploration

## Overview

This project focuses on exploring and analyzing product data using Microsoft Excel. The objective was to apply basic Excel functions for data summarization, conditional analysis, and text extraction from Product IDs.

## Dataset Information

The dataset contains the following fields:

- Product ID
- Product Name
- Brand Name
- Price ($)
- Quantity
- Category
- Price Range
- Day
- Country Code
- Month

## Tasks Performed

### 1. Total Price of All Products
Used the SUM function to calculate the total product price.

### 2. Total Number of Products
Used the COUNTA function to count all products in the dataset.

### 3. Average Product Price
Used the AVERAGE function to determine the average price of products.

### 4. Minimum Product Price
Used the MIN function to identify the lowest product price.

### 5. Maximum Product Price
Used the MAX function to identify the highest product price.

### 6. Product Price Classification
Used the IF function to classify products as:
- High Price (Price ≥ 500)
- Standard Price (Price < 500)

### 7. Total Price of Electronics Products
Used the SUMIF function to calculate the total value of products belonging to the Electronics category.

### 8. Count Products Below $100
Used the COUNTIF function to count products with prices less than $100.

### 9. Extract Day from Product ID
Used the LEFT function to extract the day portion from the Product ID.

### 10. Extract Country Code from Product ID
Used the RIGHT function to extract the country code from the Product ID.

### 11. Extract Month from Product ID
Used the MID function to extract the month abbreviation from the Product ID.

## Excel Functions Used

- SUM

- AVERAGE

- SUMIF
- COUNTIF
- LEFT

## Key Learnings

- Data exploration using Excel.

- Using text functions to extract meaningful information.
